# Frontend - Resource Discovery Platform

Interface React pour l'administration des ressources.

## À Venir

- React 18 + TypeScript
- Vite
- TanStack Query
- Tailwind CSS + shadcn/ui

## Setup

Le setup React sera effectué selon le guide [JOUR_1_SETUP.md](../docs/JOUR_1_SETUP.md).

```bash
# Commandes à venir
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```

Voir [../docs/JOUR_1_SETUP.md](../docs/JOUR_1_SETUP.md) pour le guide complet.
